> 이 문서는 모바일 애플리케이션 **Dutybox** (이하 "본 서비스" 또는 "앱")의 개인정보 수집·이용·보관·파기 정책을 안내합니다. 본 서비스는 「개인정보 보호법」, 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」(이하 "정보통신망법")을 준수합니다.

### 1-3. 수집하지 않는 항목

- **OCR 업로드 이미지**: 이용자가 스케줄표 자동 입력 기능을 사용할 때 업로드한 이미지는 AI 분석 직후 즉시 폐기되며, 본 서비스 서버에 저장되지 않습니다. 분석 결과(스케줄 텍스트 정보)만 저장됩니다.
- **위치 정보, 연락처, 통화 기록, SMS, 단말 식별번호(IMEI)**: 본 서비스가 직접 수집하지 않습니다. 다만 앱 내 광고 노출을 위해 Google AdMob SDK 가 광고 식별자 등을 처리할 수 있습니다(§4-3 참고).
- **구글 캘린더 연동 데이터**: 이용자가 구글 캘린더 연동(선택 기능, §4-4)을 사용하더라도 본 서비스 서버는 이용자의 구글 계정 정보·인증 토큰·캘린더 데이터를 저장하지 않습니다. 동기화는 이용자 단말과 구글 서버 간에 직접 이루어집니다.

### 3-2. 장기 미접속 시 스케줄 데이터 삭제

본 서비스는 이용자의 개인정보를 최소한으로 보관하기 위해, 이용자가 **180일 이상 본 서비스에 접속하지 않는 경우** 해당 이용자가 저장한 **스케줄 데이터를 삭제할 수 있습니다.** 본 안내는 이용자의 사전 동의를 위한 것이 아니라 처리방침 고지사항이며, 본 정책은 앱 내 안내 팝업을 통해 사전에 고지됩니다.

- 삭제 대상은 **스케줄 데이터에 한정**되며, 계정·친구 관계·프로필 정보는 그대로 유지됩니다.
- 다시 접속하여 활동하시면 미접속 기간이 초기화되어 삭제 대상에서 제외됩니다.
- 삭제된 스케줄 데이터는 복구되지 않으나, 재접속 후 다시 등록(업로드)하실 수 있습니다.

### 4-3. 광고 서비스 (Google AdMob)

본 서비스는 무료로 제공되며, 운영 비용 충당을 위해 앱 내에 **Google AdMob** 광고(메인 달력 화면 하단 배너, 친구·그룹 스케줄 비교 화면 하단 배너, 스케줄표 자동 입력 후 로딩 화면의 전면 광고)를 게재합니다.

- 본 서비스의 AdMob 광고는 **비개인맞춤 광고(Non-personalized ads)** 로 설정되어 있습니다 — 이용자의 관심사·행동 이력에 기반한 맞춤 광고를 제공하지 않으며, 광고 빈도 제한·부정 클릭 방지 등 기본적인 목적으로만 광고 식별자·기기 정보를 사용합니다.
- iOS 의 경우 본 서비스는 추적(IDFA)을 사용하지 않으므로 별도의 추적 동의(App Tracking Transparency) 창을 띄우지 않습니다.
- 광고 식별자 재설정·옵트아웃: **Android** = 휴대폰 설정 → Google → 광고 → "광고 ID 삭제"; **iOS** = 설정 → 개인정보 보호 및 보안 → Apple 광고; Google 계정 광고 설정 = [adssettings.google.com](https://adssettings.google.com).
- Google 의 광고 데이터 처리에 관한 자세한 내용은 [Google 광고 정책](https://policies.google.com/technologies/ads) 을 참고하세요.

### 4-4. 구글 캘린더 연동 (선택 기능)

본 서비스는 이용자가 원하는 경우 근무 스케줄을 이용자 본인의 **Google 캘린더**에 동기화하는 선택 기능을 제공합니다. 이 기능은 이용자가 앱 내 "캘린더 연동" 화면에서 직접 구글 계정으로 권한을 부여(OAuth 동의)할 때에만 활성화되며, 기본값은 **꺼짐**입니다. (구글 계정은 본 서비스의 로그인 수단이 아니라, 캘린더 동기화 권한만을 위한 것입니다.)

| 구분 | 내용 |
|---|---|
| 사용하는 권한(OAuth 범위) | `https://www.googleapis.com/auth/calendar.app.created` — **본 앱이 직접 생성한 "DutyBox" 캘린더에 한해** 일정을 만들고·수정·삭제할 수 있는 제한된 범위입니다. 이용자의 다른 캘린더나 본 앱이 만들지 않은 기존 일정에는 접근하지 않습니다. |
| 접근·처리하는 데이터 | 이용자가 본 앱에 저장한 근무 스케줄(날짜·근무 유형·시작/종료 시간·라벨)을 구글 캘린더 일정으로 기록 |
| 데이터 흐름 | 동기화는 **이용자 단말에서 구글 서버로 직접** 이루어지며, **본 서비스 서버는 이용자의 구글 계정 정보·액세스 토큰·캘린더 데이터를 저장하지 않습니다.** |
| 연동 해제 | 앱 내 "캘린더 연동" 화면에서 "연결 끊기"를 누르면 권한이 즉시 철회되고 동기화가 중단됩니다. 구글 계정 설정([myaccount.google.com/permissions](https://myaccount.google.com/permissions))에서도 직접 해제하실 수 있습니다. |

**Google 사용자 데이터의 제한적 사용(Limited Use):** 본 서비스가 Google API를 통해 수신한 정보의 사용 및 다른 앱으로의 전송은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)(Limited Use 요건 포함)을 준수합니다. 구체적으로 본 서비스는 구글 캘린더 데이터를 (1) 위 동기화 기능 제공이라는 이용자에게 드러나는 목적으로만 사용하고, (2) 제3자에게 양도·판매하지 않으며, (3) 광고 목적으로 사용하지 않고, (4) 사람이 해당 데이터를 열람하지 않습니다(이용자의 명시적 동의, 보안 목적, 관련 법령 준수 등 정책상 허용되는 경우는 제외).

## 5. 개인정보의 파기 절차 및 방법

### 5-1. 파기 절차

## 7. 개인정보의 안전성 확보 조치

본 서비스는 이용자의 개인정보를 안전하게 보관하기 위해 다음 조치를 취하고 있습니다.

- **암호화 통신**: 이용자 단말과 서버 간 모든 통신은 TLS(HTTPS)로 암호화됩니다.
- **비밀번호 암호화**: 이메일 가입 비밀번호는 단방향 해시(bcrypt)로 저장되어 운영자도 평문을 조회할 수 없습니다.
- **접근 통제 (Row-Level Security)**: 데이터베이스 단계에서 본인 또는 친구 관계가 확인된 경우에만 데이터 조회·수정이 가능하도록 정책을 적용합니다.
- **인증 토큰 관리**: 로그인 세션은 단기 만료되는 JWT 토큰으로 관리되며, 갱신 토큰은 단말에 안전하게 저장됩니다.
- **첨부파일 만료 URL**: 버그리포트 첨부 이미지는 7일 만료 서명 URL로만 접근 가능합니다.
- **최소 수집 원칙**: 서비스 제공에 반드시 필요한 항목만 수집하며, 위치·연락처는 수집하지 않습니다. 앱 내 광고(AdMob)는 비개인맞춤으로 설정되어 광고 식별자를 추적·맞춤 광고 용도로 사용하지 않습니다.
